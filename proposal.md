# X-Game Proposal

## Repository
[GitHub Page](https://github.com/JUB2121/X-Game)

## Description
This will consist of a simple game where the goal is to press the X on the screen. This could be a simple press on the screen or solving a simple puzzle.

## Features
-Start/End Interactions
-Creating a simple menu where the user can start the game and quit the game in the same spot with state variables and updates in pygame

-Collison
-Create collison on the screen to create obstacles for the users to complete the level with pygame.Rect and colliderect()

-Mouse Input
-Track user mouse movement with pygame.mousemovement both up/down, displayed as a sprite

## Challenges
-Look and read pygame documentation to understand how to create simple menu and display text
-Learn how to create collison with mouse and interaction with other objects on screen
-Learn through pygame documentation how to control mouse input and display it on the screen

## Outcomes
Ideal Outcome:
-The ideal outcome will a fully interactive menu that lets you start and close the game. Once started, a menu that lets you pick the level and experince the fully interactive level with a timer on how fast a level is complete

Minimal Viable Outcome:
-The minimal outcome is the game being able to run with a simple start and end button that launches the game itself. This could mean not having a menu to choose the levels but rather the level just starts.
